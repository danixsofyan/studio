# Library footage

Simpan klip mentah di sini supaya tidak perlu menyalin folder per video.
Saat membuat video, sebut nama klipnya — agen yang menyalin ke `footage/`
di folder project dan menormalkannya ke 1080×1920 SDR.

## Penamaan

```
YYYY-MM-topik-aksi-01.MOV
2026-11-clodi-cuci-01.MOV
2026-11-clodi-jemur-02.MOV
2026-10-sampah-tps-01.MOV
```

Aturan:

- huruf kecil, kata dipisah tanda hubung
- akhiran nomor urut dua digit
- satu klip = satu aksi, 5–10 detik
- rekam vertikal, HDR dimatikan (Settings › Camera › Formats › HDR Video)

## Kalau lupa isi klip

Minta contact sheet: agen bisa membuat satu gambar berisi thumbnail semua klip
beserta nama filenya, jadi kamu bisa memilih tanpa membuka satu per satu.
